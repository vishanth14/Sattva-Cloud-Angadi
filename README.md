# Sattva Cloud Angadi

A premium digital heritage-commerce experience for traditional Indian products made from copper, brass, bronze, and other heritage materials.

## Core Principle
We do not treat heritage as decoration. Every product communicates its material, cultural context, traditional ritual, craftsmanship, maker, usage, care, and long-term significance.

## Project Structure & Context
Please refer to [`PROJECT_CONTEXT.md`](./PROJECT_CONTEXT.md) for authoritative rules, module specifications, core business rules, and technical principles.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
