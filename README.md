# Sattva Cloud Angadi

An online store for traditional Indian artisan products.

## What We Sell

Handcrafted items made from:
- Copper
- Brass
- Bronze
- Kansa (bell metal)
- Iron
- Terracotta

Products include:
- Water bottles and tumblers
- Cooking pots and pans
- Ritual lamps and diyas
- Dining plates and bowls
- Home decor items

## How to Run

```bash
npm install
npm run dev
```

The app will run at `http://localhost:5173`.

## Tech Stack

- React 19
- Vite 8
- TypeScript 5
- Tailwind CSS 4
- React Router 7
- Three.js (for effects)
